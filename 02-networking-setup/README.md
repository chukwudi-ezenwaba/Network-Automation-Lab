Networking Setup

This folder contains templates and examples for configuring the network devices used in the lab. The files in this directory support the following tasks from the lab scope:

1. Configure IP addressing on device interfaces.
2. Configure VLANs for segmentation.
3. Configure remote access (SSH) on routers and switches.
4. Configure OSPF for dynamic routing.

Contents:

- `01. device_interfaces/` — Interface configuration templates and examples.
- `02. routing_configuration/` — OSPF and static route examples.
- `03. topology_diagram/` — Network topology resources used for lab deployment.

Use these templates as starting points. Edit the sample configs to match your IP plan and device models before applying them to devices.
