Setup Guide

This document provides a high-level sequence for preparing the lab before running automation:

1. Provision two Linux servers (Ubuntu and Fedora) in your hypervisor.
2. Configure basic server settings and verify system health using:
	- `01.server_setup/01.server_config/01-section_guide.md`
	- `01.server_setup/01.server_config/02-basic_server_administration.md`
3. Install essential services (run scripts in order):
	- `01.server_setup/02.setup_services/ssh_config.sh`
	- `01.server_setup/02.setup_services/install_python.sh`
	- `01.server_setup/02.setup_services/ntp_config.sh` (configure NTP)
	- `01.server_setup/02.setup_services/tftp_config.sh` (configure TFTP on Ubuntu)
	- `01.server_setup/02.setup_services/sftp_config.sh` (configure SFTP on Fedora)
4. Verify services with the provided system information scripts:
	- `01.server_setup/01.server_config/ubuntu_system_info.sh`
	- `01.server_setup/01.server_config/fedora_system_info.sh`
5. Configure device interfaces and VLANs using templates in `02-networking-setup/`.
6. Run the Python automation scripts in `03.python_scripts/` to perform testing, backups, and updates.

Follow this sequence to ensure services and tooling are available before automating network device tasks.
