Lab Overview

This lab demonstrates practical network automation using two Linux servers and a set of network devices (routers and switches). The primary objectives are to automate device configuration, manage configuration backups securely, and provide simple operational tooling to validate connectivity and routing.

Core components:

- Ubuntu server (`ubsvr01`) — Hosts TFTP for device backups, runs automation scripts, and provides a lightweight management endpoint.
- Fedora server (`fedsvr01`) — Provides secure storage for backups via SFTP and long-term archival.
- Network devices — Routers and switches configured using templates under `02-networking-setup/` and managed via Python automation scripts in `03.python_scripts/`.

Learning outcomes:

- Prepare Linux servers for automation (package updates, hostname, services).
- Install and configure essential services: SSH, TFTP, SFTP, NTP, and Python runtime.
- Use Python scripts to test connectivity, extract device information, backup and restore configurations, and orchestrate IOS/firmware updates.
- Apply basic networking tasks: interface addressing, VLAN configuration, and OSPF dynamic routing.

Prerequisites:

- A hypervisor or lab environment with two Linux VMs (Ubuntu and Fedora) and network device emulation (EVE-NG, GNS3, or physical devices).
- SSH access and sudo privileges on the servers.
- Basic familiarity with Linux shell and networking concepts (IP addressing, VLANs, routing).

Repository layout and next steps:

- `01.server_setup/` — Prepare and verify servers. Start here.
- `01.server_setup/02.setup_services/` — Install services (run `ssh_config.sh` and `install_python.sh` first).
- `02-networking-setup/` — Device configuration templates (interfaces, VLANs, routing examples).
- `03.python_scripts/` — Automation scripts and sample inventory; run `ping_test.py` to validate connectivity.
- `04.docs/` — Lab overview, setup guide, and troubleshooting reference.

Follow `04.docs/03. setup_guide.md` for the recommended setup order and `04.docs/04. troubleshooting.md` if you encounter issues.
