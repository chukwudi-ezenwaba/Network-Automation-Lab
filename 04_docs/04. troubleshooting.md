Troubleshooting

This document centralizes common troubleshooting steps and points to the section-specific guides for deeper investigation. If an issue appears while following the lab, consult the related section first (server setup, service setup, networking templates, or Python scripts).

1. Server Setup Problems

If a server fails to update or the hostname is not applied, verify the commands in `01.server_setup/01.server_config/02-basic_server_administration.md`. Common fixes:

- Ensure network connectivity and DNS resolution on the VM.
- Re-run package updates:

```bash
sudo apt update && sudo apt upgrade -y
```

- Confirm hostname and hosts file entries:

```bash
hostname
cat /etc/hosts
```

2. Service Installation and Configuration

If a service script fails (SSH, TFTP, SFTP, NTP, Python installer):

- Inspect the script output for errors and look for missing dependencies.
- For permission issues, re-run with `sudo`.
- Verify services are running:

```bash
sudo systemctl status ssh
sudo systemctl status tftpd
sudo systemctl status sshd   # SFTP uses SSH
```

3. Networking and Device Connectivity

If devices cannot reach servers or peers cannot form OSPF adjacencies:

- Verify IP addressing and VLAN assignments per templates in `02-networking-setup/01. device_interfaces/`.
- Check interface status on devices and servers:

```bash
ip a
```

- Use ping and traceroute to validate path connectivity.

4. Automation Script Failures (Python)

If a Python script fails, check the following:

- Ensure the virtual environment is activated (if used):

```bash
source /opt/network-lab/venv/bin/activate
```

- Confirm required packages are installed:

```bash
pip install -r 03.python_scripts/requirements.txt
```

- Inspect stack traces and adjust device credentials, IPs, or parsing logic.

5. Where to look next

If the quick checks above do not resolve the issue, open the section README related to the failing component and follow its troubleshooting notes:

- `01.server_setup/01.server_config/01-section_guide.md`
- `01.server_setup/02.setup_services/01-section_guide.md`
- `02-networking-setup/README.md`
- `03.python_scripts/README.md`
